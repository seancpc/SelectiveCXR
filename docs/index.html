選擇性胸腔 X 光判讀系統（SelectiveCXR）

Selective Chest X-ray Interpretation with Multi-Source Uncertainty & Conformal Error Control

會說「我不確定」的選擇性判讀 · 棄答後 selective accuracy 0.893(全答 0.805) · Conformal 校準錯誤率控制(校準分布下 ≤ α) · 單卡 RTX 4090

一個「會說我不確定」的 AI 判讀系統 —— 有把握就自動判讀,沒把握就誠實標記、交給人類專家。 以胸腔 X 光(CXR)驗證,但框架領域無關:同一套邏輯可用於缺陷檢測、金融風控等任何 「錯誤成本高 + 需要可證明信任」的場景。

設計概念

這個專案不拼判讀準確率,而是拼 可信賴的自動化 —— 讓 AI 知道自己何時不可靠,把不確定的交給人(學術上稱 selective prediction / learning to defer)。三個核心:

  • 選擇性棄答:有把握自動判讀、沒把握主動棄答轉人工,而不是對每張片子都硬給答案。
  • 多源不確定性 + 校準錯誤率控制:用三個跨 backbone 模型的判斷分歧量化不確定性,再用 conformal prediction 在校準條件下控制「自動判讀部分錯誤率 ≤ α」(資料選擇與分布偏移下不必然成立,見已知限制)。
  • 範式無關:前端判讀模型可替換(VLM / CNN / 混合),中間的不確定性與決策層完全不動 —— 這是「醫療 → 跨領域」可遷移的技術支點。

專案簡介

像一個好的實習醫師:大部分片子能獨立判讀,但知道自己什麼時候該去問主治醫師。現在的醫療 AI 最危險的不是「看錯」,而是「看錯了還很自信」—— 對每張片子都給斬釘截鐵的答案。SelectiveCXR 要做的是有「自知之明」的 AI。

  • 任務:胸腔 X 光的 14 種 CheXpert 病徵 multi-label 判定 + 三檔分流決策。
  • 驗證規模:MIMIC-CXR,calibration 1000 + test 671 張,14 病徵,α = 0.15 操作點。

系統架構

三個「出身不同」的 VLM(視覺語言模型)各自判讀同一張片子,用它們之間的判斷分歧當不確定性訊號,經 conformal 校準後做三檔分流。

              胸腔 X 光
                  │
     ┌────────────┼────────────┐
     ▼            ▼            ▼
  Qwen3-VL    MedGemma    Llama-3.2-V      ← 三個跨 backbone 的 VLM
   (通用)      (醫療)       (通用)            錯誤不相關,分歧才有意義
     └────────────┼────────────┘
                  ▼
       跨模型 disagreement(判斷分歧)        ← 不確定性訊號
                  ▼
        Conformal Prediction 校準           ← 校準條件下控制錯誤率 ≤ α
                  ▼
            三檔分流決策
     ┌────────────┼────────────┐
     ▼            ▼            ▼
   高度自動    部分標記    整案轉人工
  • 跨 backbone ensemble:刻意選三個不同來源的模型(Qwen / Gemma / Llama)。架構多樣性 → 錯誤不相關 → 它們「吵架」時才是真的難 case。
  • disagreement 當訊號:三模型對同一病徵越分歧,越可能棄答。
  • Conformal Prediction:用統計方法決定棄答門檻,在校準條件下控制錯誤率 ≤ α,而非工程師手調。
  • 三檔分流:高度自動 / 部分標記待確認 / 整案轉人工,並標出系統「天生判不準、固定交人工」的能力邊界。

成效亮點

  • 選擇性判讀核心驗證:棄答最不確定的樣本後,自動判讀部分的準確率明顯優於全答(0.893 vs 全答 0.805)。
  • 能力邊界 = 2 / 14:系統標出 disagreement 救不回的兩個高陽性率病徵(Cardiomegaly、Lung Opacity)固定交人工,其餘做選擇性判讀。(α=0.15 下 Atelectasis、Pleural Effusion 在 test 上也 100% 棄答,實際全數交人工的病徵為 4 個。)
  • CNN vs VLM(per-label AUC,不依賴 threshold):CNN 0.626 > VLM ensemble 0.585 —— VLM 判斷品質略遜專用 CNN(誠實,不誇大);但兩者逐病徵互有勝負、錯誤不相關(CNN 強密度型病灶、VLM 強型態型),這正是「CNN + VLM 混合」的理論基礎。
  • 多標籤聯合棄答(結構性發現):在嚴格 α=0.05 下,每張片子棄答數高度集中、「整張零棄答」幾乎不發生 —— 揭示多標籤 selective prediction 的結構性挑戰。展示採 α=0.15 操作點,使三檔都能呈現;α=0.05 的真實分布如實記錄,展示操作點 ≠ 隱藏真相。

Risk–Coverage 曲線(test 子集,671 張 × 12 病徵,排除 2 個能力邊界病徵,共 8,052 個標籤決策):x=自動判讀比例、y=該子集錯誤率,越貼左下越好,實測 AURC = 0.11。曲線上錯誤率 ≤15% 時最多可涵蓋 93% 的決策(以 test 結果事後排序的上限;conformal 在校準集上選門檻的實際 α=0.15 操作點 coverage 為 63.4%);但把目標收緊到 ≤5%,涵蓋率驟降至近 0 —— 系統誠實呈現「難 case 連 5% 錯誤率都達不到」,寧可交人工也不假裝達標。這是選擇性預測領域最一眼認得的招牌圖。

方法定位與已知限制

方法定位:本系統的棄答門檻不是工程師手調,而是在校準集上控制 selective risk(自動判讀子集的錯誤率 ≤ α),屬 Conformal Risk Control (CRC) 家族;可選 Hoeffding 上界提供有限樣本保證。最接近的同題工作是 AT-CXR《Uncertainty-Aware Agentic Triage for Chest X-rays》(arXiv 2508.19322)。

已知限制(誠實面對前沿爭論):近期研究指出「naive conformal prediction 不宜直接用於 selective classification」,主因有二 —— (1) conditional coverage:對「資料驅動選出的子集」,標準 conformal 的邊際保證不必然轉移;(2) distribution shift:輸入 / 盛行率偏移時保證會退化。本專案的做法是直接控制 selective risk 而非套用預測集,並用 out-of-distribution 資料(NIH,門檻在 MIMIC 校準)實測 —— 觀察到系統在 OOD 上明顯更保守,符合「不確定就別自動放行」的安全預期。

正解路標(未來工作):升級到 Conformal Risk Control / Selective Conformal Risk Control,並採用能處理 distribution shift 的變體(weighted / adaptive conformal),在偏移下恢復嚴格保證。

範圍與後續

  • CNN + VLM 混合:對比實驗已證明兩者錯誤不相關、逐病徵互有勝負 —— 把 CNN 接進同一個 selective + conformal 框架,可截長補短(框架範式無關,決策層不需改動)。
  • 跨領域遷移:同時滿足「錯誤成本高 / 有人工 fallback / 需可證明信任」的場景皆適用 —— 缺陷檢測、金融風控、保險核保等;把胸腔 X 光換成其他影像,只需更換前端判讀模型。

開發歷程

開發過程不是「一路成功」,而是一連串「遇到問題 → 驗證 → 誠實修正」。以下是幾個關鍵節點:

① 怎麼讓 AI 知道自己「不可靠」、該棄答?

解決方式:用三個跨 backbone 模型的判斷分歧(disagreement)當不確定性訊號。驗證確認有效 —— 棄答最不確定的樣本後,自動判讀部分的準確率達 0.893,高於全答的 0.805;α=0.15 下 conformal 實際錯誤率 0.107,符合「≤ α」的目標(empirical 校準,coverage 63.4%)。改用 Hoeffding 上界(δ=0.1)校準時更保守:selective accuracy 0.913、實際錯誤率 0.087、coverage 48.6%。

選擇性判讀評測(empirical,α=0.15):selective accuracy 0.893 vs 全答 0.805,conformal 實際錯誤率 0.107,coverage 0.634。

② 「病灶定位(grounding)的分歧」能不能當另一個訊號?

解決方式:用 AUC 嚴格驗證,發現跨模型 bbox IoU(定義 B,AUC 0.501)與解剖模型驗證(定義 A,AUC 0.463)都約等於 0.5(等同隨機猜測),沒有區辨力。根因是 VLM「判斷」可靠但「定位」能力本質不足 —— 誠實移除,不硬塞無效訊號。

grounding 兩種定義的預測 AUC 均約 0.5(定義 B 0.501、定義 A 0.463,等同隨機),確認無效後移除。

③ 第三模型一直跑不起來,問題出在哪?

解決方式:候選模型反覆卡在推論框架(vLLM)的版本相容性,而非模型本身。意識到「約束是 vLLM 而非模型」後,改用 transformers 跑 Llama-3.2-Vision,回到理想的跨 backbone 設計(混合引擎,對前端無影響)。

④ 通用 VLM ensemble 的判斷品質,比得上專用 CNN 嗎?

解決方式:用 per-label AUC(不依賴 threshold)做公平對比 —— CNN 0.626 略勝 VLM ensemble 0.585,誠實承認、不誇大;但兩者逐病徵互有勝負、錯誤不相關,反而成為「CNN + VLM 混合」的理論基礎。

每個病徵的 per-label AUC:CNN(青) vs VLM(橘)。CNN 平均略高(0.626 vs 0.585),但逐病徵互有勝負 —— Pneumonia、Lung Lesion、Fracture、Lung Opacity 等 VLM 反而較佳,代表兩者錯誤不相關。

原始終端機輸出,佐證上圖數據。

⑤ 嚴格 α=0.05 下幾乎全部「轉人工」,系統還可用嗎?

解決方式:診斷發現是多標籤聯合棄答的結構性挑戰(label 越多,「整張零棄答」越難發生)。改採 α=0.15 操作點 + 雙分界三檔,讓「高度自動 / 部分標記 / 整案轉人工」都能呈現;同時誠實標出 2 個 disagreement 救不回的能力邊界病徵(門檻 −inf,固定交人工)。

per-label conformal 門檻:Cardiomegaly、Lung Opacity 為 −inf(能力邊界,固定交人工)。
